CLEARVISION — CUSTOMIZED WEBSITE DEMO

HOW TO RUN
1. Extract this ZIP folder.
2. Open the clearvision_customized folder in Visual Studio Code.
3. Open index.html in a browser, or use the VS Code Live Server extension.
4. Keep the images folder next to index.html.

INCLUDED
- Responsive ClearVision landing page
- English/Hindi toggle
- Two informal eye-awareness demos
- Rule-based bilingual chatbot demo
- Pickup/drop request form demo
- Appointment request form demo
- Your supplied eye-care images

IMPORTANT LIMITATIONS
- Eye-screening activities are informal demonstrations only, not validated clinical tests.
- The chatbot uses predefined responses; it is not connected to an AI model and cannot diagnose.
- Forms do not transmit or save requests to a clinic or transport provider. They only show on-page demo confirmations.
- For real bookings, AI responses, data storage, and notifications, connect a secure backend/API. Never place secret API keys in frontend JavaScript.
- Replace any sample claims, contact information, and images/text that do not match your actual clinic/project before public use.
